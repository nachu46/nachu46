### 👨‍💻 About Me

- 👁️ **Computer Vision & AI Inference Backends**: Engineering real-time visual perception pipelines using **PyTorch**, **YOLOv8 (Ultralytics)**, **OpenCV**, and **MediaPipe** for hand/pose estimation and gesture translation.
- ⚡ **Backend & Stream Processing**: Integrating real-time video frames with asynchronous audio synthesis (**gTTS / pyttsx3**), REST APIs, and event-driven data streaming.
- 🌐 **Full-Stack Development**: Crafting modern web platforms, interactive dashboards with **Streamlit**, **React**, and deploying scalable web services on **Vercel**.
- 💡 **Clean Code & System Design**: Dedicated to robust, testable software engineering and practical AI solutions.
